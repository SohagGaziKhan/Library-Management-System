# Library Management System UI (React + Tailwind CSS)

A full-featured, modular, and responsive Library Management System front-end built using React, Vite, and Tailwind CSS.

## 🚀 How to Run Locally

1. **Unzip the project file**:
   Extract `library-management-system.zip`

2. **Install dependencies**:
   ```bash
   cd library-management-system
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Open App**:
   Visit `http://localhost:5173` in your browser.
